My work sits at the intersection of technical pre-sales, solution architecture, and applied AI—leading discovery, de-risking deals, and owning the conversation from first call through post-launch growth.

The common thread: making high-scale, high-stakes technology accessible—and turning it into revenue.

🔭 &nbsp;I'm currently working on **a single-phone listening instrument for in-person group dialogue: the room talks, the AI follows live, and it raises its hand on screen when it has a question worth asking — the host decides when to interrupt. Built on AWS Bedrock with Claude Opus for question drafting and end-of-session consensus analysis, Amazon Transcribe for streaming speech, and Titan embeddings for topic-shift and coverage detection. Everything the AI puts in front of a room passes Bedrock Guardrails first, and the transcript deletes itself within 24 hours.**
